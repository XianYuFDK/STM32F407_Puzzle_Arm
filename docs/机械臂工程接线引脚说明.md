# STM32F407VET6机械臂工程接线引脚说明

## 1. 工程信息

- 主控：STM32F407VET6
- 工程目录：`D:\STM32\HAL\26`
- 逻辑电平：3.3V
- 舵机数量：5路
- 舵机PWM：50Hz，500~2500μs对应0~180°
- USART1：K230视觉通信，115200、8N1
- USART2：电脑调试通信，115200、8N1
- 电磁铁：PD12控制高电平触发继电器

本文档根据当前的`26.ioc`、`arm_config.h`和BSP驱动源码整理。

## 3. 五路舵机接线

### 3.1 舵机编号

| 新编号 | 原机械臂编号 | 机械作用 | PWM引脚 |
|---|---:|---|---:|
| J1/舵机1 | 原2号 | 电磁铁末端旋转 | PE11 |
| J2/舵机2 | 原3号 | 腕部/末端俯仰 | PE13 |
| J3/舵机3 | 原4号 | 肘部 | PE14 |
| J4/舵机4 | 原5号 | 肩部 | PC6 |
| J5/舵机5 | 原6号 | 底座旋转 | PC7 |

原夹爪舵机已经删除。原TIM1_CH1/PE9不再输出舵机PWM，当前PE9用于
拼图完成指示。

### 3.2 每个舵机的三根线

常见舵机线色：

| 舵机线 | 连接 |
|---|---|
| 信号线（黄/橙/白） | 对应的PE11、PE13、PE14、PC6或PC7 |
| 电源正（红） | 外部舵机电源正极，通常5~6V |
| 电源地（棕/黑） | 外部舵机电源负极，并与STM32 GND共地 |

接线示意：

```text
外部5~6V电源正极 ─────── 五个舵机V+

外部电源负极 ────────── 五个舵机GND
       │
       └────────────── STM32 GND

PE11 ───────────────── 舵机1信号
PE13 ───────────────── 舵机2信号
PE14 ───────────────── 舵机3信号
PC6  ───────────────── 舵机4信号
PC7  ───────────────── 舵机5信号
```

### 3.3 舵机供电注意事项

1. 不要用STM32开发板的3.3V引脚给舵机供电。
2. 五个大扭矩舵机不要直接使用开发板USB 5V供电。
3. 使用能够提供足够峰值电流的独立5~6V电源，电流容量建议留足余量。
4. 舵机电源地必须与STM32 GND连接，否则PWM信号没有共同参考电平。
5. 建议在舵机电源母线附近并联大容量电解电容和0.1μF陶瓷电容，减小
   舵机启动造成的压降和STM32复位。
6. PWM是3.3V信号，不能向STM32引脚输入5V。

## 4. K230视觉串口接线

USART1用于K230视觉协议：

```text
STM32 PB6 / USART1_TX ───── K230 RX
STM32 PB7 / USART1_RX ───── K230 TX
STM32 GND             ───── K230 GND
```

| 参数 | 当前值 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 接收方式 | DMA + 空闲中断 |
| DMA | DMA2 Stream2 Channel4 |

通信方向：

- STM32发送`0x3A`：启动视觉任务1。
- STM32发送`0x3B`：启动视觉任务2。
- K230向PB7发送52字节视觉结果帧。
- STM32合法接收后从PB6回复单字节`0xAC`。

注意：

1. TX与RX必须交叉连接。
2. 必须共地。
3. 使用3.3V TTL串口，禁止连接±12V的RS-232接口。
4. 本工程USART1使用PB6/PB7，不使用PA9/PA10。

## 5. 电脑调试串口接线

USART2连接USB-TTL：

```text
STM32 PA2 / USART2_TX ───── USB-TTL RX
STM32 PA3 / USART2_RX ───── USB-TTL TX
STM32 GND             ───── USB-TTL GND
```

| 参数 | 当前值 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 接收方式 | DMA + 空闲中断 |
| DMA | DMA1 Stream5 Channel4 |

USART2是ASCII文本调试口，可发送：

```text
PING
STATUS
HOME
GOTO 100 0 0 0 3000
VREAD 1
VSIM 1
VFRAME 1 <连续104位HEX>
```

USB-TTL模块选择3.3V逻辑。若STM32已经单独供电，一般只连接TX、RX和
GND，不要再用USB-TTL的VCC反向给开发板供电。

## 6. 电磁铁和继电器接线

### 6.1 控制端

PD12配置为推挽输出，高电平表示吸合：

```text
STM32 PD12 ───────── 继电器模块IN
STM32 GND  ───────── 继电器模块GND
继电器模块VCC ───── 按模块规格连接5V或其他规定电压
```

当前控制逻辑：

| PD12电平 | 继电器/电磁铁状态 |
|---|---|
| 低电平 | 关闭 |
| 高电平 | 吸合 |

固件初始化时会先输出低电平，防止上电瞬间误吸合。电磁铁最长连续吸合
保护时间当前为10秒。

### 6.2 继电器触点端

直流电磁铁推荐连接：

```text
电磁铁电源正极 ───── 继电器COM
继电器NO       ───── 电磁铁正极
电磁铁负极     ───── 电磁铁电源负极
```

在电磁铁两端并联续流二极管：

```text
二极管阴极（带色环） ───── 电磁铁正极
二极管阳极           ───── 电磁铁负极
```

安全要求：

1. PD12只能连接继电器模块的逻辑输入，不能直接驱动继电器线圈或电磁铁。
2. 确认继电器模块输入支持3.3V高电平；若不支持，增加三极管或MOSFET
   驱动级。
3. 电磁铁使用独立电源，电压和电流必须符合电磁铁铭牌。
4. 继电器触点额定电流必须大于电磁铁实际电流。

## 7. 拼图完成指示PE9

PE9当前为高电平有效的任务完成输出，不再是舵机PWM。

接普通LED：

```text
PE9 ── 330Ω~1kΩ电阻 ── LED正极
LED负极 ───────────── GND
```

若连接蜂鸣器、继电器或其他负载，必须通过三极管/MOSFET驱动，不能让
PE9直接驱动线圈。

## 8. 急停PD13

当前配置：

```c
#define ARM_ESTOP_ENABLED 0U
```

因此PD13当前未启用，暂时不要依赖它完成安全急停。

如果只按当前代码启用：

- PD13为内部上拉输入；
- 低电平判定急停；
- 应使用按下导通到GND的常开按钮。

```text
PD13 ───── 常开急停按钮 ───── GND
```

当前代码注释中曾提到常闭开关，但“内部上拉+低电平有效”与常闭接地的
失效安全逻辑不一致。若要使用常闭急停，必须先修改有效电平和安全逻辑，
不要直接照常闭方式接线。

机械急停应优先硬件切断舵机和电磁铁功率，软件PD13只能作为附加保护。

## 9. ST-Link下载与调试

| ST-Link | STM32 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V/VREF | 开发板3.3V参考电压 |
| NRST（可选） | NRST |

如果开发板由其他电源供电，ST-Link的3.3V/VREF主要用于检测目标电平，
不要同时使用多个电源互相反向供电。

## 10. 推荐供电结构

```text
                    ┌──────── STM32开发板
主逻辑电源 ─────────┤
                    └──────── K230（按K230模块规格供电）

独立5~6V大电流电源 ───────── 五路舵机

独立电磁铁电源 ───── 继电器触点 ───── 电磁铁

STM32 GND ─┬─ K230 GND
           ├─ USB-TTL GND
           ├─ 舵机电源GND
           └─ 继电器控制侧GND
```

如使用真正电气隔离的光耦继电器模块，应按模块说明区分逻辑侧和负载侧，
不要随意破坏隔离。

## 11. 上电前检查清单

- [ ] 五路舵机信号分别连接PE11、PE13、PE14、PC6、PC7。
- [ ] PE9没有误接到舵机。
- [ ] 舵机使用独立5~6V电源。
- [ ] 舵机地与STM32地共地。
- [ ] K230 TX接PB7，K230 RX接PB6。
- [ ] USB-TTL TX接PA3，USB-TTL RX接PA2。
- [ ] 串口均为3.3V TTL，不是RS-232。
- [ ] PD12只接继电器模块IN，不直接接线圈。
- [ ] 电磁铁电源与继电器触点额定值匹配。
- [ ] 电磁铁两端安装续流二极管。
- [ ] 首次上电先断开机械连杆或抬高机械臂，逐路低速测试舵机。
- [ ] 所有电源极性和共地关系检查无误。
