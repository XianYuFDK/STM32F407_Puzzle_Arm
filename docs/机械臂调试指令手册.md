# STM32F407 五轴机械臂调试指令手册

适用工程：`D:\STM32\HAL\26`

当前控制器：STM32F407VET6  
当前机械臂：幻尔开源六路舵机机械臂改五路舵机，末端使用电磁铁  
更新时间：2026-07-30

## 1. 串口分工

### 1.1 USART2：电脑文本调试口

USART2用于电脑、VOFA+或普通串口助手发送ASCII文本命令。

```text
波特率：115200
数据位：8
停止位：1
校验位：None
流控：None
电平：3.3V TTL
```

接线：

```text
USB-TTL TXD → PA3（STM32 USART2_RX）
USB-TTL RXD ← PA2（STM32 USART2_TX）
USB-TTL GND ↔ STM32 GND
```

正常启动后USART2输出：

```text
READY ARM_CLI
SEND HELP FOR COMMANDS
```

命令不区分大小写。参数使用空格分隔，数值最多保留一位小数。
推荐附加回车换行；当前DMA空闲中断也允许不附加回车换行。

USART2只接受文本，不接受视觉二进制帧。向USART2发送二进制数据会返回：

```text
ERR USART2 TEXT_ONLY; SEND HELP
```

### 1.2 USART1：K230视觉协议口

USART1只用于第一问固定52字节二进制协议。

接线：

```text
K230/USB-TTL TXD → PB7（STM32 USART1_RX）
K230/USB-TTL RXD ← PB6（STM32 USART1_TX）
K230/USB-TTL GND ↔ STM32 GND
```

串口参数同样为115200、8N1、无流控、3.3V TTL。

合法52字节计划进入队列后，STM32通过USART1回复单个二进制字节：

```text
AC
```

这里是数值`0xAC`，不是ASCII字符串`"AC"`。

需要启动视觉任务1或任务2时，在USART2分别发送文本命令：

```text
TASK1
TASK2
```

`TASK1`使STM32通过USART1发送单字节`0x3A`，`TASK2`发送单字节
`0x3B`。视觉收到后开始识别并发送52字节计划帧；固件完整校验并保存
计划后，自动发送单字节`0xAC`要求视觉停止重发，然后执行机械臂抓放。
两道题共用52字节帧，`COUNT`允许2、3或4，固件只执行有效记录。
任务2的抓取点和放置点均允许位于A4完整坐标范围内。

`STATUS`中的视觉协议诊断字段：

```text
V_TASK=2   当前由TASK2触发
V_FRAME=1  已收到1个合法52字节帧
V_BAD=0    尚未收到结构/校验/坐标非法帧
```

自动抓取时的末端动作顺序：

```text
下降到抓取高度
→ 等待 ARM_PUZZLE_PRE_PICK_SETTLE_MS
→ 电磁铁吸合
→ 等待 ARM_PUZZLE_MAGNET_ON_SETTLE_MS
→ 抬升铁片
```

完整协议见：

```text
D:\26电赛复习最新资料\26题\机械臂\UART_PROTOCOL_FINAL.md
```

## 3. A4坐标系

坐标原点：

```text
A4左边线与橙色中线交点 = (0, 0)
```

当前自动拼图不再对视觉坐标做额外平移，视觉坐标与USART2手动`GOTO`
共用同一套A4坐标系：

```text
视觉X + 0.0 mm
视觉Y + 0.0 mm
```

也就是说，如果`GOTO X Y Z M`调试坐标已经比较准，视觉模拟帧里填同样
的`X,Y`，自动抓取会按同样的坐标进入二维补偿表和逆运动学。

当前逆解内部还带有X方向机械补偿：

```text
全局X补偿：+10 mm
右中点P3补偿：X=210,Y=0处额外+20 mm，向上下边缘衰减
中段X补偿：X=105,Y=0处额外+18 mm，X=0和X=210处衰减为0
```

根据最新9点实测，固件还会在进入逆运动学前做二维坐标插值补偿：

| 目标点 | 实际点 | 补偿量 |
|---|---|---|
| `(0,-120)` | `(0,-112)` | `(0,-8)` |
| `(105,-120)` | `(95,-105)` | `(+10,-15)` |
| `(210,-120)` | `(200,-105)` | `(+10,-15)` |
| `(0,0)` | `(10,0)` | `(-10,0)` |
| `(105,0)` | `(105,0)` | `(0,0)` |
| `(210,0)` | `(210,0)` | `(0,0)` |
| `(0,120)` | `(0,105)` | `(0,+15)` |
| `(105,120)` | `(95,100)` | `(+10,+20)` |
| `(210,120)` | `(200,105)` | `(+10,+15)` |

当前补偿表比例：

```text
ARM_KIN_COORD_CORRECTION_SCALE = 0.6
```

右上/右下角如果按100%补偿会把虚拟目标推到臂展外，所以先按60%补偿，
保证远角不会直接报`IK_UNREACHABLE`。

远点电磁铁不平行时，调这个俯仰补偿：

```c
#define ARM_KIN_FAR_POINT_PITCH_COMP_MAX_DEG 5.0F
```

正值会让远点末端更“抬头”，负值会让远点末端更“低头”。如果远点电磁铁
靠前一侧下垂，先试`+5.0F`、`+8.0F`；如果靠前一侧翘起，改成`-5.0F`。

自动抓取吸合后，抬升阶段默认锁定腕部舵机J2：

```c
#define ARM_PUZZLE_LOCK_WRIST_AFTER_PICK 1U
```

也就是说，电磁铁在抓取高度压平吸住后，从抓取高度抬到安全高度时，
J2保持抓取瞬间角度不变，减少铁片在上升时被腕部舵机动作带斜。

自动抓放表面高度现在按XY查表，不再只用固定`ARM_PUZZLE_PICK_HEIGHT_MM`：

| 坐标 | 表面高度Z |
|---|---:|
| `(20,0)` | `5 mm` |
| `(105,0)` | `15 mm` |
| `(210,0)` | `15 mm` |
| `(105,-120)` | `10 mm` |
| `(105,120)` | `10 mm` |
| `(210,120)` | `20 mm` |

相关宏在`arm_config.h`的`ARM_PUZZLE_SURFACE_Z_*`。未实测角点已先按
相邻区域估计，后续测到新高度后直接改表即可。

放置前增加贴片稳定等待：

```c
#define ARM_PUZZLE_PRE_PLACE_SETTLE_MS 1500U
```

机械臂下降到放置高度后，会保持电磁铁吸合并等待这段时间，再断开电磁铁，
避免下降过程中同时释放贴片。

方向：

```text
X向右为正
Y向下为正
Z为电磁铁中心距离A4平面的高度，向上为正
```

有效A4范围：

```text
X：0～210 mm
Y：-148.5～+148.5 mm
```

上半区抓取点通常满足`Y < 0`，下半区放置点通常满足`Y > 0`。

## 5. 基础通信命令

### 获取真实视觉坐标但不启动机械臂

USART2发送：

```text
VREAD 1
```

任务2使用：

```text
VREAD 2
```

STM32分别通过USART1向K230发送单字节`0x3A`或`0x3B`。收到52字节
视觉帧后执行与自动任务完全相同的帧头、版本、数量、坐标范围、校验和
及帧尾检查，但不会把计划放入机械臂队列，也不会控制舵机或电磁铁。

返回格式示例：

```text
OK VREAD TASK=1 TX=3A PARSE_ONLY WAIT_VISION_FRAME
VISION TASK=1 SEQ=1 COUNT=4 PARSE_ONLY NO_MOTION
VISION ORDER=0 ID=3 PICK=(59.7,-34.7) PLACE=(145.7,58.9) ROTATE=-176.11
VISION ORDER=1 ID=2 PICK=(157.3,-74.1) PLACE=(99.5,98.1) ROTATE=+99.68
OK VREAD ACK=AC NO_MOTION
```

合法帧仍通过USART1回复单字节`0xAC`，使K230停止重发。5秒内没有收到
完整帧会返回`ERR VREAD TASK=1 TIMEOUT NO_MOTION`；非法帧返回
`FRAME_HEADER_CHECKSUM_OR_DATA`，两种错误均不会启动机械臂。

### 模拟视觉帧

USART2发送：

```text
VSIM 1
```

或：

```text
VSIM 2
```

固件内部注入一帧`COUNT=2`的合法52字节视觉数据：

```text
piece0: pick=(80,-60),  place=(80,60),  rotate=0
piece1: pick=(130,-60), place=(130,60), rotate=0
```

该命令不向K230发送`3A/3B`，而是直接模拟K230返回数据。数据仍会经过
正式解析、校验、任务保存和逆运动学；保存成功后USART1发送单字节
`0xAC`，机械臂开始抓放。若返回`ERR VSIM BUSY`，先等待当前动作完成
或发送`STOP`。

### 从USART2手动注入自定义视觉帧

USART2保持文本模式，将完整52字节视觉帧去掉空格，转换成连续104位
十六进制字符串后发送：

```text
VFRAME <1|2> <104_HEX_CHARS>
```

示例：

```text
VFRAME 1 AA55010102000320FDA8032002580000010514FDA8051402580000000000000000000000000000000000000000000000007B55CC
```

固件会把HEX文本还原为52字节，并执行与USART1完全相同的帧头、版本、
记录数量、坐标、校验和和帧尾检查。合法时返回：

```text
OK VFRAME TASK=1 BYTES=52 ACK=AC EXECUTING
```

该命令通过USART2发送的是ASCII文本，不能在VOFA中选择HEX发送模式；
帧内字节之间也不能带空格。调试注入会自动加入内部执行序号，因此动作
结束后可再次发送完全相同的`VFRAME`；正式USART1仍保持重复帧只ACK、
不重复执行的安全机制。

### 5.1 PING

用途：检查USART2收发是否正常。

发送：

```text
PING
```

返回：

```text
OK PONG
```

### 5.2 HELP

发送：

```text
HELP
```

返回固件当前支持的命令列表。

### 5.3 STATUS

发送：

```text
STATUS
```

典型返回：

```text
STATUS MOVING=0 MAGNET=0 ESTOP=0
J1=90.0 J2=173.0 J3=90.0 J4=90.0 J5=0.0
V_RX=0 V_BYTES=0 V_DROP=0 V_ERR=0
D_DROP=0 D_ERR=0
PUZZLE=IDLE PSEQ=0 PIECE=0 PRESULT=0
```

实际返回为一行，上面为了阅读进行了换行。

字段含义：

| 字段 | 含义 |
|---|---|
| `MOVING` | 1表示运动任务正在输出轨迹 |
| `MAGNET` | 1表示电磁铁当前吸合 |
| `ESTOP` | 1表示急停输入有效 |
| `J1～J5` | 当前软件记录的五路舵机角度 |
| `V_RX` | USART1产生的有效DMA接收事件数量 |
| `V_BYTES` | USART1累计收到的字节数 |
| `V_DROP` | USART1接收块队列丢弃次数 |
| `V_ERR` | USART1硬件错误次数 |
| `D_DROP` | USART2接收块队列丢弃次数 |
| `D_ERR` | USART2硬件错误次数 |
| `PUZZLE` | 拼图状态 |
| `PSEQ` | 当前或最近一次视觉计划序号 |
| `PIECE` | 当前执行到第几块，0表示未执行 |
| `PRESULT` | 最近一次拼图结果码 |

`PUZZLE`可能状态：

```text
IDLE      空闲
QUEUED    已入队
RUNNING   正在执行
COMPLETE  执行完成
ERROR     执行出错
STOPPED   被STOP终止
```

USART1故障判断：

```text
发送视觉帧后 V_BYTES仍为0：
PB7没有收到数据，检查接线、共地和实际引脚。

V_BYTES增加但PUZZLE仍为IDLE：
字节已经进入STM32，但帧格式或校验未通过。

PUZZLE进入RUNNING但电脑收不到AC：
USART1接收正常，检查PB6返回线路。
```

## 6. 舵机直接控制

### 6.1 SERVO：控制单个舵机

格式：

```text
SERVO <1-5> <ANGLE_DEG> [TIME_MS]
```

示例：

```text
SERVO 5 90 2000
SERVO 3 45.5 1500
SERVO 1 120
```

`TIME_MS`省略时默认1000ms，最大30000ms。

命令接受后返回：

```text
OK SERVO 5 TARGET=90.0 TIME=2000
```

动作完成后返回：

```text
DONE MOVE OK (0)
```

超出舵机限位会返回：

```text
ERR SERVO ANGLE_LIMIT (5)
```

### 6.2 BASE：控制底座舵机

`BASE`是`SERVO 5`的快捷命令。

格式：

```text
BASE <ANGLE_DEG> [TIME_MS]
```

示例：

```text
BASE 90 2000
BASE 147 3000
```

当前底座方向定义：

```text
J5=180°：朝题面原点左侧
J5=90°：大致朝题面正前方
J5=0°：朝题面原点右侧
```

### 6.3 MOVE：同时控制五个舵机

格式：

```text
MOVE <J1> <J2> <J3> <J4> <J5> [TIME_MS]
```

示例：

```text
MOVE 90 173 90 90 0 3000
MOVE 90 125 117 125 147 4000
```

该命令不做坐标逆解，五个数值直接作为舵机目标角度。

动作被接受：

```text
OK MOVE OK (0)
```

动作完成：

```text
DONE MOVE OK (0)
```

### 6.4 HOME：回到归位姿态

格式：

```text
HOME [TIME_MS]
```

示例：

```text
HOME
HOME 3000
```

当前HOME：

```text
J1=90°
J2=173°
J3=90°
J4=90°
J5=0°
```

动作完成：

```text
DONE HOME OK (0)
```


## 8. 坐标逆运动学命令

### 8.1 IK：只计算，不运动

格式：

```text
IK <X_MM> <Y_MM> <Z_MM> <MAGNET_DEG>
```

参数含义：

```text
X_MM、Y_MM：A4坐标
Z_MM：电磁铁中心距离A4平面的高度
MAGNET_DEG：J1末端相对旋转角
```

示例：

```text
IK 0 0 20 0
IK 105 -70 5 0
IK 145.7 58.9 5 80
```

成功返回：

```text
IK J1=... J2=... J3=... J4=... J5=...
BASE=... SHOULDER=... ELBOW=... WRIST=...
```

`J1～J5`是最终舵机角度；`BASE/SHOULDER/ELBOW/WRIST`是逆解内部数学关节角。

不可达时：

```text
ERR IK IK_UNREACHABLE (14)
```

### 8.2 GOTO：坐标逆解并移动

格式：

```text
GOTO <X_MM> <Y_MM> <Z_MM> <MAGNET_DEG> [TIME_MS]
```

`Z_MM`以A4纸面为零点。当前A4纸铺在7 mm厚平板上，固件会自动把该
高度加入逆解；上位机不要再次手工加7 mm。例如纸面上方15 mm仍发送
`Z_MM=15`，内部实际按底座安装面上方22 mm解算。

当前实机还启用了统一的X方向补偿：逆解内部使用`X_eff=X_MM+10 mm`。
上位机和视觉仍发送原A4坐标，不要重复增加10 mm。

示例：

```text
GOTO 105 0 20 0 3000
GOTO 105 0 5 0 2000
GOTO 59.7 -34.7 20 0 3000
```

固件先完成逆解和限位检查，成功后才提交运动。

接受后返回：

```text
OK GOTO X=105.0 Y=0.0 Z=20.0 M=0.0
J1=... J2=... J3=... J4=... J5=... TIME=3000
```

动作完成：

```text
DONE GOTO OK (0)
```

安全范围：

```text
0 ≤ X ≤ 210
-148.5 ≤ Y ≤ 148.5
Z ≥ 0
```

超出A4范围：

```text
ERR GOTO OUT_OF_BOARD
```

逆解不可达：

```text
ERR GOTO IK_UNREACHABLE (14)
```

建议先在20mm安全高度验证XY，再下降到5mm：

```text
GOTO 105 0 20 0 3000
GOTO 105 0 5 0 2000
```

## 9. A4六点校准命令

六个校准点：

| 点位 | 坐标/mm | 位置 |
|---|---|---|
| P1 | `(0, -148.5)` | 左上 |
| P2 | `(210, -148.5)` | 右上 |
| P3 | `(210, 0)` | 右中 |
| P4 | `(210, 148.5)` | 右下 |
| P5 | `(0, 148.5)` | 左下 |
| P6 | `(0, 0)` | 左中/坐标原点 |

### 9.1 CALIB CHECK

发送：

```text
CALIB CHECK
```

作用：

- 只进行逆解和限位预检；
- 不驱动舵机；
- 检查原点`(0,0)`和六个校准点。

六点全部可达时：

```text
CALIB CHECK HEIGHT=5.0 MASK=0X3F
CALIB P1 ... OK J1=... J2=... J3=... J4=... J5=...
...
OK CALIB CHECK OK (0)
```

`MASK`的bit0～bit5对应P1～P6，`0X3F`表示六点全部可达。

### 9.2 CALIB POINT

格式：

```text
CALIB POINT <1-6>
```

示例：

```text
CALIB POINT 1
CALIB POINT 6
```

机械臂移动到对应点的5mm高度并停留，方便人工测量。

接受后：

```text
OK CALIB POINT OK (0)
```

完成后：

```text
DONE CALIB POINT=1 OK (0)
```

### 9.3 CALIB START

发送：

```text
CALIB START
```

执行过程：

1. 移动到A4坐标原点`(0,0)`；
2. 停留观察后回HOME；
3. 移动到P1，停留观察；
4. 回HOME；
5. 移动到P2，停留观察；
6. 以此类推执行到P6；
7. 每个点之间都回HOME，便于检查机械臂坐标系与A4纸是否对齐；
8. 全过程不吸合电磁铁。

接受后：

```text
OK CALIB START OK (0)
```

完成后：

```text
DONE CALIB OK (0)
```

返回示例：


状态可能为：


### 9.5 CALIB STOP

发送：


返回：


## 10. USART1视觉模拟帧

电脑端脚本：

```text
D:\STM32\HAL\26\tools\puzzle1_uart_test.py
```

进入工具目录：

```powershell
cd D:\STM32\HAL\26\tools
```

只校验和解码测试帧，不发送：

```powershell
python .\puzzle1_uart_test.py
```

真正从USART1发送并启动机械臂：

```powershell
python .\puzzle1_uart_test.py --port COM9 --send
```

将`COM9`替换为连接PB6/PB7的USB-TTL实际端口。发送前必须关闭占用该端口的
VOFA+或其他串口助手。

当前测试帧：

```text
AA 55 01 01 04
03 02 33 FE 46 05 B1 02 4D 45 4C
02 06 6C FC 8A 03 E3 03 D5 37 AF
01 03 61 FC 91 03 9B 02 BA 3E 2F
00 05 BA FE 13 02 A4 01 BF D9 1F
9D 55 CC
```

解码结果：

| order | ID | 抓取坐标/mm | 放置坐标/mm | 旋转角 |
|---:|---:|---|---|---:|
| 0 | 3 | `(56.3, -44.2)` | `(145.7, 58.9)` | `+177.40°` |
| 1 | 2 | `(164.4, -88.6)` | `(99.5, 98.1)` | `+142.55°` |
| 2 | 1 | `(86.5, -87.9)` | `(92.3, 69.8)` | `+159.19°` |
| 3 | 0 | `(146.6, -49.3)` | `(67.6, 44.7)` | `-99.53°` |

`order`是机械臂执行顺序，`ID`是碎片编号。旋转角正数为顺时针，负数为
逆时针。固件会同时补偿抓取点和放置点之间的底座偏航变化，因此旋转角
不会直接原样作为J1舵机角度。

成功时脚本显示：

```text
ACK received: AC
```

随后机械臂执行：

```text
20mm抓取点上方
→ 下降到5mm
→ 电磁铁吸合
→ 抬升到20mm
→ 搬运到放置点
→ 下降到5mm
→ 电磁铁释放
→ 抬升
→ 处理下一块
→ 四块完成后回HOME
```

同一个52字节包重发时，STM32会再次回复`0xAC`，但不会重复执行。

## 12. 推荐调试顺序

首次通电建议断开电磁铁和舵机动力电源，先确认通信：

```text
PING
STATUS
```

然后空载、低速检查单关节：

```text
SERVO 1 90 2000
SERVO 2 173 2000
SERVO 3 90 2000
SERVO 4 90 2000
SERVO 5 0 2000
HOME 3000
```

检查逆解但不运动：

```text
CALIB CHECK
IK 0 0 20 0
IK 105 0 20 0
IK 210 0 20 0
```

安装软质指针并在20mm安全高度测试：

```text
GOTO 0 0 20 0 3000
GOTO 105 0 20 0 3000
GOTO 210 0 20 0 3000
```

确认方向和位置正确后再执行：

```text
CALIB POINT 1
CALIB START
```

最后才连接电磁铁和舵机动力，发送视觉模拟帧。

## 13. 安全注意事项

- 调试舵机方向时先拆除负载或抬高机械臂；
- 首次运动使用2000～5000ms慢速；
- 不要直接从未知姿态高速下降到`Z=5mm`；
- 先用`IK`检查，再用`GOTO`运动；
- `OK`通常只表示命令已接受，必须等待`DONE`才表示动作完成；
- `MAGNET ON`会真实吸合电磁铁；
- 视觉测试脚本加`--send`后会真实执行四块抓放动作；
- 发送视觉帧前清除机械臂周围障碍物；
- 发生异常立即发送`STOP`并切断舵机动力电源；
- 不要使用5V串口信号直接连接STM32 GPIO。
