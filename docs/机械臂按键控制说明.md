# 机械臂按键控制说明

## 接线方式

当前程序默认启用 10 个独立按键：

- 按键一端接 STM32 GPIO。
- 按键另一端接 GND。
- GPIO 使用内部上拉。
- 按下为低电平触发。
- 软件扫描周期为 10 ms，防抖时间为 40 ms。

如果按键模块为高电平触发，需要修改 `App/Inc/arm_config.h`：

```c
#define ARM_BUTTON_ACTIVE_LEVEL            GPIO_PIN_SET
#define ARM_BUTTON_GPIO_PULL               GPIO_PULLDOWN
```

## 默认引脚

| 按键 | 默认引脚 | 动作 |
|---|---|---|
| KEY1 | PE0 | 启动视觉任务1，USART1发送 `3A`，等待视觉坐标帧并执行机械臂 |
| KEY2 | PE1 | 启动视觉任务2，USART1发送 `3B`，等待视觉坐标帧并执行机械臂 |
| KEY3 | PE2 | 启动视觉任务3，USART1发送 `3C`，等待视觉坐标帧并执行机械臂 |
| KEY4 | PE3 | 执行 `GOTO 0 0 1 0 3000` |
| KEY5 | PE4 | 执行 `GOTO 105 -70 1 0 3000` |
| KEY6 | PE5 | 执行 `GOTO 105 70 1 0 3000` |
| KEY7 | PE6 | 机械臂回到 HOME，时间 3000 ms |
| KEY8 | PE7 | 强制停机，停止拼图/校准/运动并关闭电磁铁 |
| KEY9 | PE8 | 视觉校准，USART1发送 `3F`，不启动机械臂 |
| KEY10 | PE10 | 视觉辅助校准，USART1发送 `AD`，不启动机械臂 |

## 修改按键引脚

所有按键引脚都在 `App/Inc/arm_config.h` 中配置：

```c
#define ARM_BUTTON1_GPIO_PORT              GPIOE
#define ARM_BUTTON1_GPIO_PIN               GPIO_PIN_0
```

如果实际接线不同，只需要修改对应 `GPIO_PORT` 和 `GPIO_PIN`。

## 注意事项

- KEY1、KEY2、KEY3 会启动机械臂自动抓放，按下前应确认机械臂附近安全。
- KEY8 为强制停机，任何时候按下都会关闭电磁铁。
- KEY9、KEY10 只向视觉模块发送单字节命令，不等待 52 字节坐标帧。
- 若正在执行机械臂动作，KEY1~KEY7 会被忙状态保护拦截，不会插入新的运动。
- 默认引脚 PE0~PE8、PE10 已写入 `26.ioc`，但运行时由 `arm_buttons.c` 自行初始化，不依赖重新生成 CubeMX 代码。
