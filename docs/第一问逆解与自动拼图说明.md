# E题第一问逆解与自动拼图说明

## 1. 当前实现范围

当前固件已按第一问固定四片碎片完成下面的数据链：

```text
K230识别并生成四片计划
    ↓ USART1，固定52字节包
STM32校验、去重并回复单字节0xAC
    ↓
一次性预解算四片的全部抓放姿态
    ↓
FreeRTOS拼图任务依次执行四片抓取、搬运、旋转和放置
    ↓
回到HOME，PE9完成指示拉高，USART2输出DONE PUZZLE
```

第一问题面自备碎片拼成的目标矩形为 `10 cm × 6 cm`。视觉负责决定每片
的抓取中心、放置中心和需要旋转的角度；STM32负责坐标转换、逆运动学、
五路舵机目标角、动作时序、电磁铁和安全停止。

## 2. 已确认机械参数

所有长度都必须按旋转轴中心测量：

| 参数 | 数值 | 定义 |
|---|---:|---|
| `L1` | 165.0 mm | 肩轴中心到肘轴中心（原仿真105.0 mm，加长60.0 mm） |
| `L2` | 153.0 mm | 肘轴中心到腕轴中心（原仿真90.0 mm，加长63.0 mm） |
| `L3` | 80.0 mm | 腕轴中心到电磁铁吸附中心 |
| `H` | 90.0 mm | 肩轴中心距底座安装面的实测高度 |
| `D0` | 10.0 mm | 底座旋转轴到肩轴的径向偏置 |
| `Zboard` | 7.0 mm | A4纸所在平板相对底座安装面的高度 |

题面坐标原点为A4左边线与中间分界线交点：

```text
X向右为正
Y向下为正
Z从纸面向上为正
底座旋转中心纸面投影：(-70, 0) mm
机械臂正前方：题面+X
实机目标补偿：进入逆解前统一使用 X_eff=X+10 mm
```

这些参数集中在 `App/Inc/arm_config.h`，以后重新测量后只修改配置，不要
直接改逆解公式。

## 3. 逆运动学

### 3.1 底座角

先把题面坐标变换到肩轴纸面投影：

```text
dx = (X+10) - base_x
dy = Y - base_y
r  = sqrt(dx² + dy²) - D0
q_base = atan2(dy, dx)
```

机械臂位于A4左侧，题面 `+X` 是机械臂正前方，向 `+Y` 旋转为正。从A4
纸上方向下看，`+X`转向`+Y`为顺时针，与视觉协议的正方向一致。

### 3.2 平面三关节

全部舵机90°的侧视照片确认，腕轴到电磁铁中心的80mm向量竖直向上。
抓放时电磁铁中心需要位于腕轴下方，因此将末端向量的绝对俯仰设为
`alpha=-90°`（题面+X为0°、向上为+90°）：

```text
wx = r - L3*cos(alpha)
wz = (Z+Zboard-H) - L3*sin(alpha)

c2 = (wx²+wz²-L1²-L2²)/(2*L1*L2)
q_elbow = atan2(±sqrt(1-c2²), c2)
q_shoulder = atan2(wz,wx)
             - atan2(L2*sin(q_elbow), L1+L2*cos(q_elbow))
q_wrist = alpha-q_shoulder-q_elbow
```

程序会尝试肘部正、负两个分支，并在换算为实际五路舵机角后检查所有限位。
如果 `c2` 超出 `[-1,1]` 或两个分支都越界，整套计划在电磁铁吸合前直接
拒绝，不会把错误角度强行裁剪到限位。

### 3.3 末端旋转补偿

视觉给出的旋转角是铁片在纸面世界坐标中的旋转量。底座从抓取点转向放置
点时也会带动铁片旋转，因此末端舵机实际补偿：

```text
delta = normalize(
    vision_rotate - (place_base_yaw-pick_base_yaw)
)
```

电磁铁圆面吸附时初始转角可自由选择，程序把该转角均分：

```text
抓取时末端相对角 = -delta/2
放置时末端相对角 = +delta/2
```

这样能最大化180°末端舵机的有效范围。

## 4. 五路舵机映射

逆解输出数组顺序固定为：

```text
J1：电磁铁旋转
J2：腕部俯仰
J3：肘部
J4：肩部
J5：底座旋转
```

当前初始映射为：

```text
J1 =  90° + magnet_relative
J2 =  83° - q_wrist
J3 =   0° - q_elbow = β3
J4 = 180° - q_shoulder

其中肘部逻辑弯曲角 `β3=-q_elbow`。机械臂完全伸直时定义
`β3=0°`，对应当前舵盘安装下的物理舵机指令 `J3=0°`。J3机械端点
约为180°；为避免撞击，软件硬限位设为0°～175°，因此当前允许的
逻辑弯曲范围为 `β3=0°～175°`。
J5 =  90° - q_base
```

底座映射依据实测“0°在原点右侧、180°在原点左侧”，并暂按90°正对
A4原点处理。J2、J3、J4依据90°基准照片和各自100°测试照片建立零位；
逆解优先选择前臂向A4弯曲的负肘分支。映射仍取决于实际舵盘安装齿位。
实机运行第一套计划前，必须确认
`ARM_KIN_*_ZERO_ANGLE_X10` 和 `ARM_KIN_*_DIRECTION`。软件解算正确并不
代表未经标定的舵机会朝正确方向运动。

## 5. 第一问动作顺序

纸面吸取/放置高度已按实测统一为5 mm，搬运高度为20 mm。每片执行：

1. 电磁铁关闭，移动到抓取点上方20 mm。
2. 下降到抓取高度5 mm。
3. 电磁铁吸合，等待200 ms。
4. 抬升到20 mm。
5. 移动到放置点上方，同时完成底座和末端旋转。
6. 下降到放置高度5 mm。
7. 电磁铁关闭，等待150 ms。
8. 抬升到20 mm。

四片完成后机械臂回到HOME。默认动作参数完成四片明显小于2分钟，固件
仍设置115秒整套超时保护。

20 mm搬运高度是根据当前几何预检确定的。末端角固定-90°时，过高的
Z仍可能进入长上臂、加长前臂形成的内侧盲区，不能未经检查直接改成
50 mm。修改高度后应先使用USART2的 `IK` 命令检查所有抓放点。

## 6. USART1视觉协议

USART1使用 `UART_PROTOCOL_PUZZLE1_V2.md` 的冻结协议：

```text
115200，8N1
固定52字节
AA 55 01 SEQ 04 + 4×11字节记录 + CHECKSUM + 55 CC
坐标：int16大端，0.1 mm
旋转：int16大端，0.01°
ACK：单字节0xAC
```

解析器支持半包、粘包、前导残留字节和连续包。完整校验项目包括：

- 帧头、版本、固定四片数量和帧尾；
- 偏移2～48的8位累加校验；
- 四个ID为0～3且互不重复；
- 抓取点位于A4上半区；
- 放置点位于A4下半区；
- 旋转角在 `(-180°,180°]`。

固件对完整52字节包计算签名。同一个包重发时重新回复 `0xAC`，但不会再次
执行；正在执行另一套不同计划时不回复ACK，让K230稍后重发。

USART1不再混发旧版CRC控制帧，避免K230把其他二进制回复误认为ACK。

## 7. FreeRTOS任务

| 任务 | 优先级 | 职责 |
|---|---:|---|
| `ArmSafety` | 48 | 急停、电磁铁超时、通信超时 |
| `ArmMotion` | 40 | 20 ms平滑关节插值 |
| `ArmComm` | 32 | USART1计划、USART2文本命令和ACK |
| `ArmPuzzle` | 30 | 预解算和四片动作状态机 |
| `defaultTask` | 24 | CubeMX保留任务 |

`ArmPuzzle`低于`ArmComm`，保证通信任务先发出 `0xAC`，然后机械动作才开始。
运动期间 `ArmPuzzle`阻塞等待动作完成，不会忙等占用CPU。

## 9. USART2调试

### 9.1 只解算、不移动

```text
IK <X_MM> <Y_MM> <Z_MM> <MAGNET_DEG>
```

例如：

```text
IK 103.3 -116.0 5.0 0
```

返回五路逻辑舵机角和四个数学关节角。`IK`命令不会驱动舵机，适合在上电
前检查可达性。

### 9.2 手动模拟单个视觉坐标并移动

```text
GOTO <X_MM> <Y_MM> <Z_MM> <MAGNET_DEG> [TIME_MS]
```

例如先移动到A4中心上方20 mm：

```text
GOTO 105 0 20 0 2000
```

STM32会检查A4坐标范围、完成逆解、检查五路舵机限位后再启动运动。该命令
只控制舵机，不会打开电磁铁。`MAGNET_DEG`是J1相对中位的铁片平面旋转角；
填0表示J1保持90°。需要吸放测试时必须分步发送：

```text
GOTO 105 0 20 0 2000
GOTO 105 0 5 0 800
MAGNET ON
GOTO 105 0 20 0 800
MAGNET OFF
```

上位机脚本等价命令：

```powershell
python tools/arm_pc_serial.py --port COM5 goto 105 0 20 0 --duration 2000
```

完整边框校准使用 `CALIB START`：先到P1上方20mm并下降到5mm，再以约15mm/s按
`P1→P2→P3→P4→P5→P6→P1`闭合巡边。边框每10mm重新解算一次，保持
5mm高度和末端平行，闭合后抬升到20mm再回HOME。`CALIB POINT n`仍只
移动到单个点。

### 9.3 查询拼图状态

发送：

```text
STATUS
```

新增字段：

```text
PUZZLE=IDLE|QUEUED|RUNNING|COMPLETE|ERROR|STOPPED
PSEQ=计划序号
PIECE=当前执行片号1~4，非运行时为0
PRESULT=最近结果码
```

成功完成后USART2输出：

```text
DONE PUZZLE OK (0)
```

逆解失败时：

```text
ERR PUZZLE IK_UNREACHABLE (14)
```

任何时候发送 `STOP` 都会中止运动、关闭电磁铁并让拼图任务退出。

### 9.4 USART1示例包测试

先不接舵机电源，只连接USB-TTL到USART1：

```powershell
python -m pip install pyserial
python tools/puzzle1_uart_test.py
python tools/puzzle1_uart_test.py --port COM5 --send
```

第一条只在电脑端检查示例包；加 `--send` 才真正发送。STM32接受后应回复：

```text
AC
```

注意：示例包会启动完整机械动作。没有完成舵机方向、零位和限位校准时，
不要给舵机电源上电，也不要使用 `--send`。

## 10. 完成指示

原夹爪舵机通道 `PE9` 已释放并改名为 `PUZZLE_DONE`：

```text
开始/运行/失败：低电平
四片完成并回HOME：高电平
```

PE9只能接带限流电阻的LED，或接蜂鸣器/MOSFET驱动板的逻辑输入。若所用
模块低电平有效，修改 `ARM_PUZZLE_DONE_ACTIVE_LEVEL`。

## 11. 实机调试顺序

1. 断开电磁铁和五路舵机动力电源，只给STM32与串口供电。
2. USART2发送 `PING`、`STATUS`，确认任务正常。
3. 对协议示例8个XY点分别发送 `IK`，确认均返回角度。
4. 逐个舵机使用 `SERVO` 命令低速确认方向、机械零位和安全限位。
5. 修正 `ARM_KIN_*_ZERO_ANGLE_X10`、`ARM_KIN_*_DIRECTION`。
6. 先悬空测试单个纸面坐标，不吸铁片。
7. 接电磁铁驱动板，确认 `MAGNET ON/OFF` 和吸合高度。
8. 用自备测试片执行一片抓放，再执行完整四片计划。
9. 最后调整工作高度、搬运高度和各动作时间。

如果出现舵机顶死、结构碰撞、电源压降或STM32复位，应立即切断舵机动力
电源。软件STOP不能代替物理断电。

## 12. J3物理零位修正后的逆解复核

当前实机参数为：

```text
L1=165.0 mm，L2=153.0 mm，L3=80.0 mm
肩轴高度=90.0 mm，A4平面高度=7.0 mm，底座到肩轴径向偏移=10.0 mm
底座纸面坐标=(-70.0, 0.0) mm
末端绝对俯仰=-90°
```

对纸面坐标 `(X,Y,Z)`，侧视平面内的腕轴目标为：

```text
R  = sqrt((X+10+70)^2 + Y^2)
Xw = R - 10
Zw = Z + 7 - 90 + 80 = Z - 3
```

负肘分支按下式求解：

```text
q_elbow    = -acos((Xw^2+Zw^2-L1^2-L2^2)/(2*L1*L2))
q_shoulder = atan2(Zw,Xw)
             - atan2(L2*sin(q_elbow),L1+L2*cos(q_elbow))
q_wrist    = -90° - q_shoulder - q_elbow
```

所以任意已解算姿态都严格满足：

```text
q_shoulder + q_elbow + q_wrist = -90°
```

也就是腕轴到电磁铁中心的方向始终垂直纸面，电磁铁吸附面始终平行A4。
J1只绕该垂直轴旋转铁片，不改变吸附面的平行关系。

物理舵机映射为：

```text
J2 =  83° - q_wrist
J3 =   0° - q_elbow
J4 = 180° - q_shoulder
J5 =  90° - atan2(Y,X+10+70)
```

几何逆解后叠加A4六点经验补偿。补偿在左/右边界以及上/下半区之间做
分段双线性插值，视觉给出的任意A4坐标都会得到连续修正。5 mm校准平面的
六个节点如下：

| 点位 | J1 | J2 | J3 | J4 | J5 | 数据来源 |
|---|---:|---:|---:|---:|---:|---|
| P1左上 | 90.0° | 111.0° | 117.0° | 125.0° | 147.0° | 实测 |
| P2右上 | 90.0° | 166.0° | 24.0° | 163.0° | 114.0° | 实测 |
| P3右中 | 90.0° | 148.9° | 57.0° | 147.1° | 90.0° | J3/J5实测，其余拟合 |
| P4右下 | 90.0° | 169.0° | 21.0° | 163.0° | 60.0° | J3/J5实测，其余拟合 |
| P5左下 | 90.0° | 114.0° | 119.0° | 120.0° | 30.9° | J3/J4实测，其余拟合 |
| P6左中 | 90.0° | 80.5° | 151.9° | 120.6° | 89.0° | 当前拟合 |

对整张A4区域 `X=0～210 mm、Y=-148.5～148.5 mm` 以0.5 mm间隔扫描，
在Z=5 mm和Z=20 mm各检查250495个坐标，均无不可达点。各关节覆盖范围：

| 舵机 | Z=5 mm | Z=20 mm | 软件限位 |
|---|---|---|---|
| J2腕部 | 80.5°～169.0° | 95.0°～171.9° | 0°～180° |
| J3肘部 | 21.0°～152.0° | 20.8°～151.8° | 0°～175° |
| J4肩部 | 116.5°～163.0° | 105.5°～160.3° | 0°～180° |
| J5底座 | 30.9°～147.0° | 30.9°～147.0° | 0°～180° |

最小理论限位余量出现在Z=20 mm的J2，约为8.1°。插值时由J3、J4补偿量
反算J2补偿，任意坐标均严格保持 `J2+J3+J4=353°`。当前P3/P4/P5仍含
部分拟合值，P6完全为拟合值，后续实测可直接更新配置表。

当前上电HOME为
`J1=90°、J2=173°、J3=90°、J4=90°、J5=0°`。其中
`J2+J3+J4=353°`，与当前抓放姿态约束一致，使电磁铁吸附面保持平行A4。
该姿态会在上电时直接输出，首次下载后必须断开舵机动力确认机械空间，再
接通动力测试。
