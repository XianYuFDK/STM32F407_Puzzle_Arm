# A4六点巡边校准说明

## 1. 功能边界

本功能用于验证“题面坐标 → 逆运动学 → 五路舵机”的整体误差，不是带
反馈的自动参数辨识。STM32会按理论模型把末端依次移动到A4纸六个边界
点，操作者用软质指针、直尺或视觉画面记录实际落点误差，再修改安装坐标、
舵机零位等参数。

没有编码器、末端相机或K230闭环测量时，程序不能仅凭舵机指令知道末端
真实位置，因此不能自动算出校正量。

## 2. 坐标与巡边顺序

题面原点为A4左边线和中间橙色分界线的交点，X向右、Y向下，单位mm。

| 点号 | 位置 | X/mm | Y/mm |
|---|---|---:|---:|
| P1 | 左上顶角 | 0.0 | -148.5 |
| P2 | 右上顶角 | 210.0 | -148.5 |
| P3 | 右边线与中线交点 | 210.0 | 0.0 |
| P4 | 右下顶角 | 210.0 | 148.5 |
| P5 | 左下顶角 | 0.0 | 148.5 |
| P6 | 左边线与中线交点 | 0.0 | 0.0 |

自动巡边先用3000ms到P1正上方20mm，再用2000ms下降到5mm，然后按
P1 → P2 → P3 → P4 → P5 → P6 → P1沿A4边框闭合一周，最后用3000ms
回HOME；闭合后会先用2000ms抬回P1上方20mm。巡边高度为纸面上方5mm，
边框每10mm重新逆解一个坐标，速度约
15mm/s，每个编号点停留1500ms，电磁铁始终关闭。

边框插补小段使用连续线性速度，不在每个10mm插补点做零速启停；只有
P1～P6编号点按设定时间停留。到P1、升降和回HOME仍使用柔和启停曲线。

## 3. USART2命令

串口参数为115200、8N1、ASCII文本发送。

```text
CALIB CHECK
```

只计算六点，不驱动舵机。返回掩码中bit0～bit5分别代表P1～P6；
当前模型六点均可达时返回`MASK=0X3F`。

```text
CALIB POINT 3
```

只移动到P3并停在该点，适合逐点测量。单点不可达会直接返回
`IK_UNREACHABLE`，不会启动运动。

```text
CALIB START
```

启动前预解算六个编号点和约102个边框插补点。全部可达才开始自动巡边；
任何一个插补点不可达都会整套拒绝执行。巡边不是六个关节姿态间的直连，
而是沿题面XY边框分段计算姿态。

```text
CALIB STATUS
CALIB STOP
STOP
```

分别用于查询状态、停止校准，以及停止当前全部动作。急停和安全保护也会
终止校准任务。

## 4. 当前参数的预检结论

当前模型使用：

- 肩轴到肘轴165mm（原仿真105mm，加长60mm）；
- 肘轴到腕轴153mm（原仿真90mm，加长63mm）；
- 腕轴到电磁铁中心80mm；
- 肩轴高度90mm；
- 底座旋转中心位于A4左侧，纸面投影(-70,0)mm；
- 底座90°正对A4原点，0°转向原点右侧、180°转向原点左侧；
- 五路舵机逻辑范围暂设0～180°。

按照片确认“原点后方70mm”为题面-X方向。进一步根据全部90°基准姿态
肘腕加长到153mm后，实物确认电磁铁位于腕轴正上方，抓放末端绝对
俯仰为-90°；实测J2=173°时吸附面平行A4，对应腕部数学零位83°。
最新机械零位确认J3=0°为完全伸直，J3向175°方向弯曲。
当前暂时关闭六点实机拟合补偿，只使用更新后的纯理论几何逆解。

当前5mm校准节点为：

| 点 | J2 | J3 | J4 | J5 | 来源 |
|---|---:|---:|---:|---:|---|
| P1 | 111.0° | 117.0° | 125.0° | 147.0° | 实测 |
| P2 | 166.0° | 24.0° | 163.0° | 114.0° | 实测 |
| P3 | 148.9° | 57.0° | 147.1° | 90.0° | 部分实测 |
| P4 | 169.0° | 21.0° | 163.0° | 60.0° | 部分实测 |
| P5 | 114.0° | 119.0° | 120.0° | 30.9° | 部分实测 |
| P6 | 80.5° | 151.9° | 120.6° | 89.0° | 当前拟合 |

补偿在A4左/右边界、上/下半区之间做分段双线性插值，视觉发送的任意
抓取和放置XY都会经过同一补偿面；吸取和放置高度均为5mm。

这只是几何模型预检。首次执行`CALIB START`前，先发送
`SERVO 5 90 2000`，确认机械臂确实正对A4原点；若不是，立即停止并重新
标定底座舵盘方向。

## 5. 完成实物校准还需要的数据

1. 继续确认底座90°是否正对A4原点；0°在原点右、180°在原点左已经
   用于确定当前方向。
2. 五路舵机1500us时的实际机械角，以及逻辑角增大时的真实转向。
3. 五个关节在不碰撞条件下的安全最小角、最大角。
4. 用尺复测底座旋转中心相对题面原点是否确为(-70,0)mm。
5. 肩轴距纸面的实际高度，以及电磁铁最低面到腕轴的空间偏置。
6. 指针到达六点后的实际X/Y误差；若用K230闭环校准，还需要能识别的
   末端标记及像素到题面坐标的单应性矩阵。

相关集中参数位于`App/Inc/arm_config.h`的“第一问机械臂几何模型”和
“A4六点巡边校准”两节。
